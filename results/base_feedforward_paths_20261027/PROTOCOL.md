# 已知底盘前馈在其他任务中的对照协议

保持S22已测试的分配器、导纳参数、物理模型、摩擦抓取和10Hz转发。只增加底盘计划对正弦及转圈几何的支持；不进行任务后的调参、不删除不利结果。

三项任务：S11直线12s、sinusoid正弦12s、S12转圈22s；各保留1s HOLD。每项原被动与主动各3次，交错顺序见schedule.json。S12沿用已有的S12导纳阻尼20覆盖，不影响其他任务参数。所有人体阻抗、限幅、抓取深度和XML与现生产配置一致。

## 独立底盘路径

- S11：已知相对路径 `[0,0]→[0,-.8]`。
- sinusoid：已知XY幅值 `[.20,.12]`、1周期、12s；底盘不接收竖直或姿态正弦前馈。该任务的人端仍使用原有完整六维目标和人体阻抗。
- S12：已知任务参考点的四段180°计划；按独立配置的初始参考点到底盘偏移 `r=[-2.395,.65,0]m` 计算底盘计划：

```
p_base_ref = base_anchor + delta_p_reference + (R_reference-I) r
v_base_ref = v_reference + omega_reference × (R_reference r)
```

偏移来自既有初始场景的几何：底盘[-3,2]、任务参考点[-.605,1.35]。运行中仅以odom的TRACK起点为底盘锚，不读取人的实时目标位姿或真实动作来重算计划；末端角速度继续使用腕部角导纳，不使用计划姿态。已知双方路径和进度同步是本实验前提，不是未知意图预测。

S12底盘的计划终点相对初始为[2.79,-1.30]m，因人和机器人位于板两侧，不应直接使用人手的[-2,0]m终点。

## 保持的速度限制

仍使用前一原型计划输入的0.25m/s、0.10rad/s上限，原QP/末端速度界也保留。该上限会裁剪部分参考，不能把它隐藏或称所有名义轨迹都被原样执行。

离线计划审计：S11不裁剪；正弦约6.35%的TRACK计划平移速度被裁剪；S12约48.68%的TRACK计划平移和62.17%的计划偏航速度被裁剪。计划峰值分别见planned_velocity_audit.json。运行日志另记录实际采样的裁剪比例。此项只能确认存在参考裁剪，不能单凭它断言某个物理误差就是由裁剪导致；本轮不做速度上限调优。

## 代码与完整性

新文件均在本目录；前一S22实验目录和生产代码不改。angular_priority.py与前一原型逐字相同。experimental_qp只替换路径构造及增加裁剪日志；导纳仍执行原生产类的方法。PlannedBasePath不依赖ROS、人体测量或目标话题。

新增测试验证：S22路径逐点等价、所有路径的解析速度等于位置数值微分、转圈两端几何及平面运动、正弦无竖直/角前馈。连同既有分配器性质测试，共7项通过。

用手端水平RMSE、水平交互力RMS、实际木板总姿态误差/滚转、终点偏航误差、接触、任务力矩及角任务分配残差评价。角导纳在计算上保留不等于实际姿态没有变化；主动运动会改变交互wrench和接触动力学。

所有失败/缺失/非有限值、任务未完成或接触中断均需单独报告，不能只平均完成的有利运行。初始偏置和受力随ROS运行存在波动，3次只用于当前模型条件下的重复验证，不宣称统计显著性或全局稳定性。
