# 已知底盘轨迹前馈：S22首轮完整对照

2026-10-27。目的：在纯被动全身导纳的基础上，向机器人提供已知底盘轨迹以主动搬运；末端角速度继续由原角导纳决定。本轮做出了隔离实验原型，未替换生产控制器。

## 已完成结果

三组各三次独立ROS进程、交错运行，全为当前摩擦抓取、S22原24秒轨迹+1秒保持；每次1251条history样本。九次均完成任务并正常退出、记录器退出0、无超时，数值有限。没有删除差结果或只挑成功运行。

|控制条件（各3次）|手端水平RMSE cm|人端水平合力RMS N|木板总姿态误差峰值 °|滚转峰值 °|
|---|---:|---:|---:|---:|
|原始被动基线|5.60–6.73|5.61–6.72|6.74–6.94|0.27–0.36|
|新分配器，前馈为零|9.05–9.21|9.04–9.21|18.07–18.77|12.94–13.93|
|新分配器，已知底盘路径前馈|1.38–1.79|1.42–1.82|2.30–3.20|0.28–0.35|

按各组均值计算，相对原被动基线，主动组手端水平RMSE降低约74%，人端水平合力RMS降低约73%。这是本模型、已知计划、S22节奏下的小样本结果，不是统计显著性/任意任务保证，也不是整体人体负担减轻的证明。

角任务优先分配器本身并没有改善所有指标：零前馈消融组更差，滚转达约13–14°，显示“在QP中保持理想角速度任务”并不足以保证实际接触动力学效果好。该组仅为消融试验，未替代原被动基线。主动组相对相同分配器的零前馈组也有明确改善，因此收益不能只归于角任务优先约束。

## 保持角导纳具体意味着什么

原始QP文件未改，原质量-阻尼角导纳、wrench测量/滤波/死区/限幅和积分代码继续执行。原型取其角速度输出作为最高优先级的末端角速度任务，没有读取路径姿态来生成末端角速度，没有姿态位置跟踪或固定姿态。

主动组每次记录的 `J_angular u - w_adm` 最大绝对分量小于1e-6 rad/s（实际为浮点舍入量级），未出现角任务不可行。合成非零角导纳/底盘转向和不可行角任务的性质测试3项通过。

但实际运动并非无误差：用机器人EE位姿做0.1秒对称旋转差分，并对齐记录的角导纳命令，主动组三次近似角速度跟踪RMS为0.0087–0.0293 rad/s。这是平滑后的执行偏差诊断，不是完整扰动辨识或导纳频响验证。真实闭环角导纳命令可随主动运动改变交互力而变化，不能要求新旧轨迹的角速度逐点相同。木板姿态与夹爪姿态也不是在摩擦模型中严格相等。

## 抓取与底盘执行的实际限制

主动组三次任务末端均仍夹持。两次双侧接触率100%，一次99.768%，后者存在短暂接触力中断，最长连续4ms；不能称全程双侧正法向力均为100%。没有复现整板脱手或大幅翻滚。零前馈组也存在最长4ms的接触力中断，其更差姿态结果如表保留。

主动组底盘自身的路径XY误差RMS为4.10–8.11cm，存在执行滞后和终点偏差，见 `base_path_execution.png`。本轮路径位置误差反馈增益为0，提供的是名义速度前馈，不是精确底盘位置控制。原底盘XY滤波和10Hz指令转发均保持不变，实测coordinator约10Hz、QP发布约99.6–100Hz。

人端竖直力在各次初始化和动态条件下有明显变化，主动组三次均值也不是一致的：约8.99–18.66N。没有通过此实验确立竖直负载分担机制，不能把水平交互力降低扩展为承重减轻。

## 具体控制定义

详见 `ACTIVE_DESIGN.md`。

- 底盘参考由独立 `robot_path.yaml` 给出，以自身odom的TRACK起点为锚；本轮路径几何和任务S22一致，时间计划一致。
- 路径速度构成名义搬运平移，原线性导纳作为柔顺修正。这改变了原绝对世界系线速度任务，是明确的主动控制新条件。
- 末端角速度仍为原角导纳输出。全身QP让机械臂补偿底盘的角速度贡献；达不到参考时底盘/平移任务让步。
- 当前只验证S22的平移折线，计划底盘偏航固定。初始姿态运动学算例含底盘转向，但不能据此声称整场S12主动转圈验证通过。

所有新增运行代码和launch在本实验目录。`production_integrity.json`验证原QP、coordinator、正式launch、人端、guard、YAML和机器人/木板XML在九次运行及最终状态均与实验前一致。旧纯被动控制仍按原launch运行。没有修改人体阻抗、摩擦系数、抓取位置、载荷前馈或指令转发频率。

实验专用guard明确标记新模式。记录器通用condition仍为human_robot，具体控制条件以每次的 `control_condition.json` 和experimental params为准，不把新结果误归为纯被动。

## 复现

容器内：

```bash
source /opt/ros/jazzy/setup.bash
source /workspace/pr2_ws/install/setup.bash
cd /workspace
FASTDDS_BUILTIN_TRANSPORTS=UDPv4 python3 results/base_feedforward_20261027/run_case.py demo_active_01 --mode active --viewer
```

使用新tag避免覆盖既有实验；`--mode passive`运行原基线，`--mode zero_feedforward`运行消融条件。零前馈消融不等于停用新原型后的原始被动行为，停用请用passive或原正式launch。

重算：`python3 summarize.py` → `python3 validate_results.py` → `python3 plot_results.py`（均在本目录，且已source ROS工作区）。
