# 已知底盘路径前馈 + 末端角导纳

用户目标：纯被动全身导纳作为基线，开始探索主动协同搬运。机器人获得已知的底盘参考轨迹，末端姿态继续受交互力矩驱动的角导纳控制。

## 参考定义

`robot_path.yaml`单独定义底盘路径。第一轮取折线S22的任务几何：相对底盘TRACK起点 `[0,0] → [.3,-.5] → [-.3,-1]`，24s，分段五次多项式零速启停，底盘计划偏航固定。机器人读取自身odom和任务阶段/仿真时钟；不读取虚拟人的实时目标位姿生成该路径。双方使用一致的任务计划，属于已知路径前馈；这不同于此前只允许腕部力输入的被动条件。

`v_b_plan = d(p_b_ref)/dt`。首轮位置误差反馈增益为0，只研究前馈；路径实际存在执行误差，不称精确底盘跟踪。

## 控制结构

原始质量-阻尼导纳代码不变：

```
M_v dot(v_adm) + D_v v_adm = F_measured
M_w dot(w_adm) + D_w w_adm = tau_measured
```

仍使用原有wrench滤波、死区、限幅与积分方式。机器人测到的wrench会随主动运动改变，因此新旧闭环下的导纳输出不必逐点相同。

新增平移任务：

```
v_EE_ref = v_adm + J_base_linear v_b_plan
w_EE_ref = w_adm
```

这使线性导纳成为围绕名义搬运运动的柔顺修正，而不是维持原有绝对世界系线速度。这是本实验明确改变的控制定义，不能说“只在QP后加一个底盘速度，其余行为完全不变”。合成线速度参考沿用原末端速度限幅。

分配QP：

```
min .5 ||J_linear u - v_EE_ref||²
    + .5 ||E_base u - v_b_plan||²
    + .005 ||u||²
s.t. J_angular u = w_adm
     u_min <= u <= u_max
```

角任务不可行时，先求限幅下最接近 `w_adm` 的角速度，再锁定该可实现结果、优化平移/底盘。不可行情况显式记录，不能把饱和后的结果冒充无误差角导纳。

不加入姿态目标、姿态误差闭环或姿态冻结。底盘转向时机械臂通过全身雅可比补偿其末端角速度贡献；参考路径只提供名义运动，不直接规定末端朝向。该优先级是运动学速度层的保证，实际跟踪仍受执行器、10Hz保持、接触与延迟影响。

## 隔离实现与对照

- 所有新增代码位于本实验目录。生产QP、coordinator、正式launch、人体模型与摩擦XML不改动。
- `experimental_qp.py`继承原QP节点；`SolverAdapter`只在TRACK/HOLD替换速度分配。原导纳计算、滤波、状态同步与发布代码原样运行。
- 原型明确允许启用阶段有路径时无wrench也运动，这是主动控制的必要区别；停用条件仍用原节点的冻结逻辑。
- `known_path.launch.py`复用正式launch的机器人、人端、记录器等节点，只替换实验QP和实验guard。实验guard仍检查摩擦抓取、无载荷补偿、角导纳未被姿态控制替换，并检查新控制模式；明确记录active/passive，避免误标成纯被动。
- `control_condition.json`是区分控制条件的侧车元数据。通用记录器的condition仍为human_robot，不能仅据这个字段把新实验归入纯被动条件。
- 原底盘输出滤波、世界系/车体系变换和10Hz coordinator保持不变。底盘XY滤波会影响线速度任务的实际实现；不把QP中的理想线速度当实测速度。
- `production_hashes_before.json`及`before_production/`保存生产源码；每次运行记录所有相关源码哈希。最终再核对无生产变化。

三个条件用于区分作用：

1. `passive`：原始QP，无新分配器，无轨迹前馈。
2. `zero_feedforward`：新角任务优先分配器，路径速度设为0，保留同样的底盘偏好权重。用于检查分配结构自身的作用。
3. `active`：与2相同的分配器，启用已知路径的名义平移和底盘参考。

因此只有active相对于zero_feedforward的改善，才能归因于这套前馈通道，而不是把角任务优先约束本身的作用算进前馈收益。主基线仍是1。

## 验证边界

三个分配器性质测试已通过：无交互力时名义前进、底盘转向/非零角导纳下保留角任务、角任务不可行时报告残差并遵守限幅。实际闭环试验覆盖独立进程下的完整S22 TRACK+HOLD，记录全部运行，不删去差结果。

需要同时看手端轨迹、交互力、木板姿态、实际底盘路径、接触和求解残差。不能仅凭姿态角更小声称角导纳仍成立，也不能仅凭角任务残差小声称动力学稳定。

本轮尚未验证S12大角度转圈、其他路径、未知人体速度、人体偏离计划、障碍物、接触丢失后的恢复或硬件。没有被动性/全局稳定性证明。人端竖直力也可能随姿态和控制分配变化，不能把任何承重变化直接归因于水平轨迹前馈。
